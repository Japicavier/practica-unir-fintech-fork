# FinTech Solutions - Word Sorter

Pequeña aplicación de ejemplo para practicar el flujo de trabajo
con Git y GitHub.

La aplicación recibe varias palabras como argumentos y las muestra
ordenadas alfabéticamente.

## Requisitos

- Python 3
- Git

## Ejecución

```bash
python3 main.py casa perro arbol coche
```

Resultado esperado:

```text
Palabras ordenadas:
arbol
casa
coche
perro
```

También se puede ejecutar mediante Make:

```bash
make run
```

## Objetivo

Este proyecto se utiliza para practicar:

- Repositorios remotos
- Forks
- Ramas
- Commits
- Pull requests
- Revisión de código
- Merge
